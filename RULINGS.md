# Dial contract rulings

### RL-1 — Invitation links do not reveal private manage authority

Date: 2026-10-19 (14:11 UTC). Ruled by: ct. Clauses: NOTIFY-009, NOTIFY-013, NOTIFY-014.

The default invitation link asks explicitly to email a replacement manage link only to the stored invitee address. The request rotates the earlier manage capability. A calendar description is readable by guests, delegates and shared-calendar viewers, so it never receives the manage token. Event types can offer separate calendar-scoped direct Reschedule and Cancel capabilities with the limited disclosure and replacement behavior stated in the clause.

### RL-2 — Priced and saved-card approval scope

Date: 2026-10-22. Ruled by: ct. Clauses: EVENT-008, PAY-007.

Priced and saved-card-fee approval belongs to PAY-007. The earlier refusal is withdrawn for upfront and deposit prices without saved-card fees and free saved-card-fee types. Combined price or deposit plus saved-card fees keeps the manual authorization, consent and capture-or-void/detach cycle. No status is promoted by recording this scope.
