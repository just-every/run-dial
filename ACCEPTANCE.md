Run `pnpm verify` on the exact frozen candidate. Preserve original assertions, fixtures and applied migration bytes. Require complete test discovery, successful migration replay and build; isolated passing diagnostics do not waive an aggregate failure. Verify the locked sources and a clean clone independently.
